# 修改记录 2026-10-15 · v2.17.18 · hmg-admin 手机版全面体检

## 反馈

「要适配手机版，不能出现异常，要详细检查，有没有视觉没有对齐的地方，特别是手机版」。

## 审计方法（390×844 IAB，逐页程序化 + 截图目检）

1. **横向溢出**：`documentElement.scrollWidth > clientWidth` 判整页横滚；再逐元素
   `right > vw+1` 且**祖先链无 overflow 裁剪**判定真越界（排除横滚容器的合法子项）。
2. **对齐度量**：`.hmg-main` 直接子元素左/右缘集合——六页统一 `12..368`（12px 页边距全对齐）。
3. **轨道真凶定位**：逐个隐藏 grid 子元素读 `gridTemplateColumns` + `width:min-content` 直测
   各层内在宽度（CSSOM 遍历注意：`CSSStyleRule.cssRules` 恒为对象，须查 `.length`）。
4. **组件态**：编辑弹窗（全屏 sheet 0,0,390,844 零溢出）、抽屉（滑入/mask/品牌可见）。

## 取证陷阱（本轮实录）

- **IAB goto() 走启发式缓存**：资产改动后 goto 导航可能拿到旧 hmg.css——一轮「抽屉打不开」
  假异常即源于此（旧表无 drawer-open 规则）。审计前必须 `reload()` 强制再验证；
  拍摄/测量读数互相矛盾时先怀疑缓存再看代码。
- stats 页卡片首拍「发虚」为 5s 轮询增量的入场动画中帧，等 ≥3.5s 稳定态再取证。
