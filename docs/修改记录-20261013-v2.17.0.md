## 关键最终态（跨仓移植锚点）

**Elevation**（hmg.css token 段）：卡片 `box-shadow: var(--edge), var(--shadow-card)`，`--edge: inset 0 1px 0 rgba(255,255,255,.035)`（亮色 .8）= 品牌"pixel rendered"顶边高光；hover 仅表面抬升（surface-1→2 + hairline→strong），**不位移不加投影**；浮层专用 `--shadow-pop` 两层投影；遮罩 backdrop-blur 7px。

**动效 token**：`--ease-out: cubic-bezier(0.23,1,0.32,1)`、`--ease-io`、`--ease-drawer: cubic-bezier(0.32,0.72,0,1)`；时长 --t1 130ms / --t2 200ms / --t3 300ms；按钮 `:active { transform: scale(.97) }`（transition transform 160ms）。

**弹窗生命周期**（hmg.js hmgOpenModal）：`document.body.appendChild(mask); void mask.offsetWidth; mask.classList.add("on")` 入场（300ms 缩放 .965+淡入）；close() 加 `.off`（140ms 恒快于入场）后 `setTimeout(() => mask.remove(), 160)`，`mask.__closing` 防重入；CSS 侧 `.mask{opacity:0;transition} .mask.on{opacity:1} .mask.off{opacity:0}` + `.modal{transform:translateY(12px) scale(.965)} .mask.on .modal{transform:none}`。菜单同构 + JS 按 `x+mw/2 < innerWidth/2` 设 transform-origin（左右）与 openedUp（上下）；toast 同构（.on/.out）。

**入场编排**：`.hmg-main` 300ms 浮起 + `.stagger > *` 40ms 级差 360ms backwards（cap 320ms）；stats/插件卡各自 `animation: hmgIn .36s backwards`（stats 的内联 `animation-delay` 由此生效）；增量渲染只建新卡→动画只在创建时播。

**彩色标签**：双主题四组 `--ok/warn/err/acc-ink + -tint`（暗色文字提亮保对比）；`badge-ok/warn/err/acc` 换 tint 底；免费绿 / **付费琥珀（信息非错误）** / 思考映射强调色 / 其余中性 pill。

**去噪**：`.btn-danger` 改 err-tint 底 hover 才描边；`@media (hover:hover) and (pointer:fine)` 内 `.model-row .m-actions` 默认隐藏、`:hover/:focus-within` 滑入（触屏恒显）；拖拽把手 opacity .55→1。

**减动效**（降级为少而柔，非全关）：`animation-duration:.01ms` 全局 + `.hmg-main/.stagger>*/.fade-in` 改纯淡入 + 弹窗菜单 toast 去 transform + 进度条去宽度过渡。
