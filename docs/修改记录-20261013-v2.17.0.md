## 1. 用户可见面

第三管理面板 `/hmg-admin`，与 `/admin`（暗黑单页）、`/hfadmin`（白天单页）并存互不影响：

- **多页面真路由**：`/hmg-admin` → 307 → `/hmg-admin/model`；六页 `/hmg-admin/{model,pools,stats,logs,keys,plugins}`，白名单外 404。可深链/收藏/刷新。
- **单 DOM 双主题**：同一界面同一布局，`data-theme="light|dark"` 只换 CSS 变量颜色；默认跟随系统，手动切换记忆 `localStorage.hmg_theme`。
- **手机全适配**：<768 顶部紧凑栏（☰ 汉堡 + 页名 + 主题）+ 280px 抽屉；卡片单列；弹窗全屏 sheet；触控目标 ≥40px。
- 六页功能与 hfadmin 对齐（见 README v2.17.0 条目③），鉴权与旧面板共用 `localStorage.gw_key`。

**主题引导**（每页 `<head>` 内联，防 FOUC）：

```html
<script>(function(){try{var t=localStorage.getItem('hmg_theme');
if(t!=='light'&&t!=='dark')t=matchMedia('(prefers-color-scheme: light)').matches?'light':'dark';
document.documentElement.setAttribute('data-theme',t);}catch(e){document.documentElement.setAttribute('data-theme','dark');}})();</script>
```
