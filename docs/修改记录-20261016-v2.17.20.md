# 修改记录 2026-10-16 · v2.17.20 · 分组可发现性回退重做 + 收放动画

## 反馈

## v2.17.19 的错在哪（先量后改，不凭感觉）

把「对比度低 / 不被发现」落成可测指标后，两条反馈各自命中一个真实缺陷：

| 指标 | v2.17.19 暗 | v2.17.19 亮 | 判定 |
|---|---|---|---|
| 组头底 vs 画布 | **1.11** | **1.09** | 近乎隐形 |
| 成员卡 vs 画布 | 1.15 | 1.14 | **组头比它收纳的卡片还不可见** |
| 分组名文字 | 13.97 | 14.42 | 无问题 |
| 成员数 `grp-count` | 4.84 | **4.29** | 亮色跌破 AA 4.5 |

根因：v2.17.19 为表达层级把组头底从 `surface-1` 换成近透明的 `--wash`。两个后果——
①组头对画布只有 1.11，比成员卡的 1.15 还低，扫视时分组根本跳不出来；
②亮色主题的 `--wash` 是**深色**半透明，把成员数对比度从 5.32 压到 4.29。

**教训：层级 ≠ 削弱可发现性。** 用「让父级变弱」来表达从属，结果连父级本身都看不见了。

## 修法一：实心面 + 强调边（替代削弱式层级）

| 元素 | 改法 | 实测（暗 / 亮） |
|---|---|---|
| 组头底 | `--wash` → `--surface-2` 实心面 | vs 画布 1.11 → **1.26**（已高于成员卡 1.15） |
| 左色条 | 2px hairline → **3px `--accent`** | vs 画布 **3.92 / 4.12**（双主题最强可发现性载体） |
| 描边 | 无 → `--hairline` 1px | vs 画布 1.46 / 1.17 |
| 投影 | 无（保持非卡片语义） | `box-shadow: none` |
| 组头字号 | 12.5px → **13px**（找回 v2.17.18 尺寸） | — |
| 成员数 | `--ink-tertiary` → **`--ink-subtle`** | 4.84 → **5.91** / 4.29 → **5.81**（双主题过 AA） |
| 「未分组」 | 透明 → `surface-1` + hairline 色条 | 退一档但不隐形 |

层级信号（缩进 28px + 2px 竖导轨）与 `.grp-inner` 的 `minmax(0,1fr)` 横滚修复原样保留。
左色条沿用 v2.17.15 P1-3「身份色承担分组」的既有先例（供应商卡 `pc-hue-N` 3px 色条）。

## 修法二：收放动画（1fr → 0fr 高度过渡）

**目的**（工作单 §16.7「动效必须答出目的」）：让「这些卡片正在被收进／放出一个组」
的因果关系可见——正对 v2.17.19 反馈里「关联度较差」那条，不是装饰。

- `.grp-body` 只开**一条行**，`1fr` ↔ `0fr`；`0fr` 把唯一子项压成 0 高，
  溢出由 `.grp-inner { overflow: hidden }` 裁掉 → 高度可 transition（旧方案
  `display:none` 不可过渡）。
- 不写死 `max-height`，组内几张卡都无需量高。
- 时长 `--t2` 200ms（工作单 UI <300ms 红线内），`--ease-out`；三角标同步到 200ms。
- 减动效：全局规则只压 `animation-*`，**不覆盖 `transition-*`**，故显式补
  `.grp-body/.grp-inner/.grp-caret { transition-duration: .01ms !important }`。

### 取证陷阱（本轮实录，两条都写进注释）

1. **假动画**：`grid-template-rows` 展开态写 `minmax(0,1fr)`、折叠写 `0fr`——
   两者 **track sizing 函数不同**（minmax vs 定值）Chrome 无法插值。
   `document.getAnimations()` 仍报一条 `state: "running"` 的 `CSSTransition`
   （**不可拿它当动画存在的证据**），但 44 帧采样零中间值、直接 1243→0 跳变。
   改成 `1fr` → `0fr`（可插值形态）后轨迹变为 `1243 → 20 → 9 → 3 → 1 → 0`。
   「auto 最小值顶住轨道」的老问题只存在于**未显式声明行**的情形，本行已显式声明。
2. **隐形点击带**：`.grp-inner` 为末卡投影留的 `padding-bottom:8px + margin-bottom:-8px`
   在收起后仍撑出 8px——`elementFromPoint` 实测**可命中**（`hitInside: true`），
   折叠后组头下方会有一条看不见但能点的带子。收起态一并归零后 `hitInside: false`。
