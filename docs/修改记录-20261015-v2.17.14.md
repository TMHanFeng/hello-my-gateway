# 修改记录 2026-10-15 · v2.17.14 · hmg-admin 背景每页身份色

## 反馈

用户（8660 IAB 停在 `/hmg-admin/model`）：「后台管理的背景还是太单一了」——即 v2.17.13 舷光
（单色 accent 光带 alpha .12）仍不足以打破平底感。

## 诊断：为什么还显得单一

v2.17.13 的氛围层其实已有 9 层（噪点/暗角/舷光/两盏顶辉光/双层网格/两盏底角辉光/极光团），
但：①全部挤在同一靛蓝-紫-青色系且 alpha 低到接近不可感知（.05～.12 + 大 blur），实际观感
≈「略带紫的深灰」；②六个页面共享完全相同的一套颜色——切页零差异，「单一」一半来自这里。

## 方案与取舍

**核心：每页一组身份色，四层背景吃同一组变量，切页即换「房间光」。**

- 每页六页六组 `--aura-a/b/c` 裸三元组挂在 `body[data-page]` 上（`rgb(var(--aura-x) / α)` 消费）；
  model 保持品牌靛蓝作默认，pools 紫 / stats 青 / logs 天蓝 / keys 紫红 / plugins 青绿。
- 两案否决记录：
  - *等 alpha + 原亮色三元组*：青/青绿亮度高，峰值叠点 ink-subtle 跌到 4.18/3.84（AA 破线）——否；
  - *统一 alpha + 按页加深三元组保 AA*：搜出的加深版全是泥色（如青 → `37,119,148`），身份感尽失——否。
  - 定稿：*色相全亮 + alpha 全局统一（暗 .15/.12/.10、亮 .075/.06/.07）+ 仅 plugins 整页 0.92×V 微降*。
- WCAG 数值实测（脚本算 relative luminance，非目测）：两主题 × 六页 × 两处峰值叠点
  （舷光核心 / 左上 glowB+极光团簇）ink-subtle 全部 ≥4.5:1。ink-tertiary 不另设阈值：其使用面约束
  （只许 canvas/surface-1 的空态与卡内）本就不进 aura 顶带。
- `html::before` 底角辉光**不吃**变量：自定义属性不向上继承，html::before 看不到 body 作用域的
  `--aura-*`（选择器陷阱清单 +1）。底角保持品牌靛青静态，页面身份由 body 侧四层承担。
- 平底两件套同步提亮：双层网格暗 .024/.013→.05/.028、亮 .022/.012→.032/.016；暗角 .38→.46
  （顶部亮带与暗角拉开的值域才是「不单底色」的体感来源）；新增 115° 斜向光轴（aura-a /.05）。
