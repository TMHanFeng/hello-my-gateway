# 修改记录 2026-10-16 · v2.17.19 · hmg-admin 全屏铺满 + 分组层级重构

## 反馈

> 「①当我打开全屏时，界面右侧 1/5 位置存在背景但是类似于模型池、供应商等等组件都在此不展示，
> 好似宽度只设置到了左侧 4/5。②供应商、模型池等的分组，感觉组与内部的模型关联度较差，打开组后
> 同等规模没有体现出从属关系，容易混淆，因为目前是独立显示的。」

## 问题与修法

| # | 级别 | 问题 | 根因 | 修法 |
|---|---|---|---|---|
| 1 | P0 | 全屏右侧约 1/5 只有背景，组件不展示 | `.hmg-main { max-width: 1492px }` 把内容列钉死（该值含 244px 左侧留白），视口宽于它时右侧只剩背景。1920 屏实测内容右缘 1460px、右侧空白 420px（≈1/5） | 去掉上限，内容铺满；1920 实测右缘 1460 → **1888**（= 1920−32 右内边距） |
| 2 | P1 | 组与成员读作同级，无从属感 | 组头 `.grp-head` 与成员卡 `.card` **同为** `surface-1` 底 + hairline 描边 + 圆角 + 投影，成员区仅缩进 2px | 三重信号表达父子（见下） |
| 3 | P1 | `pools.html` 分组只认 localStorage | 该页**漏调** `gwGroupsBoot()`——`model.html`/`index.html`/`hfadmin.html` 三页都调了。后果：换设备/换浏览器首开模型池看不到服务端已配的分组，v2.16.8 #54 的跨端共享在该页失效 | 与其余三页对齐，补 `gwGroupsBoot().finally(...)` |
| 4 | P1 | 390px 手机端整页横滚 31px | **既有问题（本次缩进前已存在）**：`.grp-body` 未声明列模板，隐式轨道按内容最大尺寸定档，成员卡内 nowrap 文本（`provider-head` 的 `min-width:220px` + `.model-row` 整行）的 min-content **393px** 顶爆轨道——正是 v2.17.18 在 `.grid` 上修过、漏掉 `.grp-body` 的同一类 bug | `grid-template-columns: minmax(0,1fr)`（与 `.grid` 同款教科书修法） |

## 问题 2 的层级语言（改后三件事同时表达父子）

1. **组头降级为「区段栏」**：去掉卡面/描边/投影，改弱底 `var(--wash)` + 左色条，视觉权重明确
   **低于**成员卡（实测 `box-shadow: none`，成员卡仍带完整三层投影）。
2. **成员整体缩进 28px**（窄屏收到 16px，层级信号保留但不让成员卡再窄一截）。
3. **成员区左侧挂竖导轨** `border-left`，把成员串挂在组头之下；折叠时导轨随体内
   `display:none` 一并消失，组头独立成一条窄栏。

「未分组」作为兜底桶进一步弱化（左色条降级、标题字重降级），不再与真分组抢注意力。
stats 页自建 `.stat-group/.stat-ogroup` 类，与 `.grp-*` 无交集，零影响。

## 验证（8660 实例 · Playwright 多视口实测）

- **铺满**：1920 / 1440 / 768 / 390 四档 × model/pools 两页，`scrollWidth == clientWidth`
  全部零横滚；内容右缘 1888 / 1408 / 748 / 378（= 视口 − 右内边距）。
- **层级**：组头 `box-shadow: none` + 底 `rgba(255,255,255,.043)`（暗）/ `rgba(22,23,27,.043)`（亮）
  对成员卡 `rgb(31,33,43)` / `rgb(255,255,255)`；缩进桌面 28px / 窄屏 16px。
- **双主题**：暗色、亮色（v2.17.16 灰底白卡）各截一组特写，层级信号均成立。
- **交互无回归**：组头点击折叠/展开（4 成员往返不变）、3 个分组节 `.grp-body` 拖拽落点
  全部可定位（`grpSyncFromDOM` 依赖 `sec.querySelector('.grp-body')`）、分组管理面板
  正常列出「模型模型 2 组 / 4 成员 / 1 成员」。
- 回归 **293/293** 全绿（与 v2.17.18 基线同数，零回归；T40k/T40t/T40w 共享资产与移动端
  加固锚点均通过）。

## 取证陷阱（本轮实录）

- **In-app Browser 的 FilePanel 只有 639 CSS px 宽**，Ctrl+− 缩放对该面板无效，无法复刻
  1920 全屏。改用 Playwright 自建 1920/1440/768/390 视口取证——量测与截图同源，
  `getBoundingClientRect` 直读，不受面板宽度限制。
- **既有横滚要 A/B 定性**：`.grp-body` 横滚并非本次缩进引入（v2.17.18 原样即 407px > 390），
  用注入原值覆盖的 A/B 实测确认后才修，避免把既有 bug 记成新引入或漏判为回归。
