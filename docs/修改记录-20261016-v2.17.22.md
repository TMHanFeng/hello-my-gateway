## 逐项实录

### C1 — index.html 补 reduced-motion 兜底（CRITICAL，无障碍）

原文件**零** `prefers-reduced-motion`，而 `hfadmin.html` 有 4 处、`hmg.css` 有 1 处——历史遗留
不同步。两处 infinite 循环（`ping 1.8s` 状态点扩散、`sheen 2.6s` 扫光）对前庭功能障碍用户是
持续刺激。照 `hfadmin.html:713` 写法补齐，另加两条收尾：装饰扫光在 `duration:.01ms` 下会闪一帧
后停在 `translateX(-100%)` 初始位，不如直接 `animation:none`；进度条 width 过渡归 0。

**实测**（Playwright `reduced_motion` 模拟，非仅查规则存在）：

| | `.dot::after` animation |
|---|---|
| `no-preference` | `ping` / 1.8s |
| `reduce` | **`none`** / 0s |

### C2 — `.stat-fill` 双路径叠乘（CRITICAL）

`index.html:334` 与 `hfadmin.html:514` 同款写法：同时挂 `transition: width` 与
`animation: fillIn`(scaleX)，可见宽度 = `width(t) × scaleX(t)`，两条 ease-out 叠乘后前段快得
不是设计出来的曲线。两文件均删除 `animation: fillIn` + `transform-origin` 与随之失效的
`@keyframes fillIn`（已确认全仓无其他引用）。JS 侧本就是双 rAF 后设 `f.style.width` 触发过渡，
不依赖 fillIn，视觉无损。**实测 CSS 文本 `fillIn` 残留 = False。**

### H1 — stagger 预算封顶（HIGH）

清单说 `pools.html:254` 是 `${i * 35}` 无封顶，**实际早已是 `${Math.min(i * 35, 400)}`**
（skill 规定 stagger 总预算 < 500ms，该项已合规）——清单此条过期。
真正未封顶的是 `hfadmin.html:2501`，已补 `Math.min(i * 35, 400)`。

### H2-a / H2-b — 两项前提错误（HIGH）

- **`index.html:156`**：清单建议改 `translateX` + `:checked`。但 `.ts-thumb` 是
  `<span class="ts-track" onclick="location.href='/hfadmin/'">` 里的纯装饰子元素，
  **全仓无任何规则移动过它的 `left`** —— 那条 `transition:left .2s` 是死代码，不是
  「用布局属性做过渡」。照建议加 `:checked` 等于凭空造一个不存在的开关。
  处置：**只删除误导性的死声明**，保留规则其余部分。
- **`hfadmin.html:580`**：`.usage-grid/.usage-col/.usage-bar-wrap/.usage-bar` 四个类
  **全仓零 markup、零 JS 生成**——`loadKeyUsage()`（`:4370`）渲染的是**内联 SVG**，
  这四条是 SVG 重写前的遗留死 CSS。`transition: height` 从未运行过。
  处置：**不动**。删除等于删一个已废弃特性的样式，不是修动效，记为发现。

### H3 — `transition: all` 展开（HIGH）

`transition: all` 会把未来新增的任何属性纳入过渡（含会触发布局的 `width/height/margin`），
等于给后续维护埋雷。4 处按各自 hover 实际变化集展开：

| 位置 | 展开为 |
|---|---|
| `.btn` | `background-color, color, border-color, box-shadow, transform`（amber:hover 动 box-shadow，:active 动 transform） |
| `.arrows button` | `color, border-color, background-color` |
| `.info-dot` | `color, border-color, background-color` |
| `.remove-x` | `color, background-color` |

**实测残留 `transition:all` = 0。**

### M1 — keyPulse 换伪元素 + 顺带修语义 bug（MEDIUM）

`box-shadow` 属 skill 性能表 Avoid 档，`keyPulse` 原是 2.6s **无休止**逐帧重绘。
改用 `.key-pill.has-key .key-dot::after` + `transform/scale`，只动合成层。

**评审未发现的语义 bug**：原 `keyPulse` **无条件**挂在 `.key-dot` 上，而 dot 背景靠
`#key-pill.has-key` 在红/绿之间切换——**未登录的红点同样在泛绿色光晕**；且动画的 box-shadow
还盖掉了 `.has-key` 上原有的静态环。现把动画收敛到 `.has-key` 才有。

**实测**：

| 状态 | 自身底色 | 自身 animation | ::after |
|---|---|---|---|
| 未登录 | `rgb(255,59,48)` 红 | `none` | `content:none` **不泛绿** |
| 已登录 | `rgb(52,199,89)` 绿 | `none` | `keyPulse` 运行 |

### M2 — 弹窗补退场动画（MEDIUM）

原 `.overlay` 靠 `display:none/flex` 切换，**退场动画为 0**；skill 要求「入场比退场长 30-50%」。

做法：**保留 display 切换**（若改成 `visibility`，`.modal` 的 `pop` 入场动画每次打开就不再
重放），关闭时先加 `.closing` 播 **150ms** 退场，到位再摘 `.show`。150ms = 入场 220ms 的 **68%**，
落在 skill「退场 = 入场的 65-75%」区间；退场用 `ease-in`（skill 方向性规则：入场减速/退场加速）。
选择器用 `.overlay.show.closing`（0,3,0）压过 `.overlay.show`（0,2,0），与声明顺序无关。

12 处打开点收敛为 `openModal(id)`，4 条关闭路径收敛为 `closeModalEl(el)`；元素上挂
`_closeTimer`，防止「关完 150ms 内又打开」被旧定时器误关。

**实测**：打开 `overlay show` / display flex → 关闭 45ms 时 `overlay show closing`、
opacity 0.84、**`fadeOut` 与 `popOut` 均 running** → 345ms 后 `overlay` / display none；
关完立刻重开仍是 `overlay show` / flex（无竞态）。

## 知情偏离记录（用户裁定不改）

- **H2-c `hmg.css` `.grp-inner { transition: padding-bottom, margin-bottom }`**（v2.17.20 引入）：
  skill 性能表把 `padding`/`margin` 列为 Poor（触发布局）。不动，理由：手风琴式展开的**可变高度
  折叠本质就是 layout 动画**，`transform` 无法对任意高度内容做真实披露；且 `grid-template-rows`
  过渡本身已触发布局，多这一两条不改变成本档位。与清单 M3「hover 非对称手感」同类——
  知情偏离，不是缺陷。
