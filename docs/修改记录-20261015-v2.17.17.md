# 修改记录 2026-10-15 · v2.17.17 · hmg-admin 亮色身份光提强

## 反馈

「白天的颜色太单调了」——v2.17.16 灰底白卡把亮色做干净了，但确实素：白卡占视口约七成，
色只能从底缝/页头透出，而亮色 aura 还是 v2.17.14 按白画布定的 .075/.06/.07，在灰画布上几不可感。

## 方案：亮色专属粉彩三元组 + 提强

直接复用暗色原色提 alpha 的死路：粉彩不变则叠画布必拉暗亮度，ink-subtle 峰值跌破 4.5
（.13/.10/.11 时 P2 已只剩 4.36——数值否决实录）。

正解：**混白 40% 的高亮度粉彩版三元组**。粉彩自身亮度高，alpha 提到 .21/.165/.175（约 2.8 倍）
也不拉低画布 L，色相浓度反而更高。六页三元组（`:root[data-theme="light"] body[data-page]`
六条覆盖——特异性必须压过亮色基座 `:root[data-theme="light"] body`，否则亮色全塌成 model 色）：

| 页 | --aura-a | --aura-b | --aura-c |
|---|---|---|---|
| model | `180 188 255` | `158 166 228` | `148 197 254` |
| pools | `202 185 252` | `191 152 234` | `158 166 228` |
| stats | `140 225 255` | `136 193 255` | `129 229 217` |
| logs | `160 201 252` | `161 163 247` | `122 229 245` |
| keys | `217 181 253` | `202 185 252` | `158 166 228` |
| plugins | `127 219 208` | `137 215 243` | `131 218 187` |

其余：斜光轴 .03→.09、底角辉光 .05→.14、html 角 .09/.07→.12/.10；
亮色双层网格从深灰线改靛调 `rgba(94,106,210,.055/.028)`（灰底蓝图感）；
亮色 --shadow-card 第二层换微靛 `rgba(94,106,210,.16)`（白卡在灰底上的一点颜色身份）。

**WCAG**：六页双峰值（canopy 全强+glowB×.35 / glowB×.9+blob×.8+canopy×.45）ink-subtle 全 ≥4.55
（min：pools 4.55）；tertiary 维持"不进 aura 顶带、不另设阈值"的使用面约束口径。

暗色全量零改动；语义 tint 零改动。
