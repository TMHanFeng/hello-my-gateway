🪴 Headroom 上下文压缩 · 插件设置

对勾选了「Headroom 上下文压缩」的模型，在其接单时自动压缩出站的大块工具输出（长 JSON 数组、日志等）以节省上游 token；同池未勾选的模型收原文，可作 A/B 对照。压缩超时或异常自动旁路，绝不影响请求本身。
启用插件（总开关）
开启后，模型编辑「流式与输出选项」里的「Headroom 上下文压缩」勾选框才可勾选。关闭时所有请求一律发原文——完全旁路，不影响转发与计费。
压缩模式
建议先用 dry_run 观察节省数据，满意后再切 live。
纯文本压缩（Kompress ML 模型）
关闭 = 纯规则压缩（仅 JSON / 工具输出等结构化大块）。开启后额外对中段自然语言消息做有损压缩：首次自动从 HuggingFace 下载模型权重（数百 MB，后台进行，就绪前该类内容照常透传原文）。
压缩参数（保持默认即可）
单条消息超过此长度才压缩，越小压得越多
结尾 N 条对话保持原样（模型正在关注的内容）
压缩耗时超限即放弃，原文直发不卡请求
保存后无需重启、无需 reload，立即按新设置运行

📦 自定义插件指南

① 在 app/plugins/installed/ 下新建文件夹（如 my_plugin）；
② 放入 manifest.json（必填 id / name / version）——仅凭清单即可获得一张可启停、可存配置的插件卡片（纯配置型插件，零代码）；
③ 需要代码能力再加 plugin.py：暴露 create_plugin(manifest) 工厂或模块级 PLUGIN 实例，继承 GatewayPlugin——on_enable/on_disable 热插拔（可注册/注销路由）、router 自带 API（挂载于 /admin/plugin_settings/<id>）、active_compressor 出站压缩 hook；
④ 回插件中心点「🔄 扫描新插件」——卡片立即出现，全程无需重启网关。

🔀 Switch 切换池 · 插件设置

插件总闸即卡片上的启用开关（停用后所有池拒绝切换请求，/v1 调用不受影响）。每个池是否响应 POST /{池名}?switch=local|net 由「模型池」页对应池卡片的 🔀 Switch 开关控制，本页仅汇总展示。

🛠 余额返还制人工校准

模型：。对齐火山控制台实际值；留空的项不修改。余额 = 昨日剩余 − 今日使用（14:00 后再加今日返还）；今日返还量即昨日使用量的校准值，将作为 14:00 的发放数额；今日使用量校准会同步今日已采与明日发放基数。校准后自当刻起按新值计算，不随跨日重算消失。
